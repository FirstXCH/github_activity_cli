# GitHub Activity CLI 🚀

A simple Command Line Interface (CLI) to fetch and display a user's recent GitHub activity right in your terminal.

> **Project idea from:** [roadmap.sh - GitHub User Activity](https://roadmap.sh/projects/github-user-activity)

## 🇬🇧 English

### Prerequisites
- Python 3.x
- `requests` library

### Installation
1. Clone this repository or download the source code.
2. Install the required libraries:
   ```bash
   pip install -r requirements.txt
   ```

### Usage
Run the script and provide a GitHub username:
```bash
python git_activity.py <username>
```
**Example:**
```bash
python git_activity.py FirstXCH
```
